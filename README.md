# Deep Learning: practical class

Two notebooks, to run in order:

1. **Score matching and diffusion models**: [open in Colab](https://colab.research.google.com/github/franciscoandrade90/deep-learning-practicals/blob/main/score_matching/practical_score_matching.ipynb)
2. **GANs**: [open in Colab](https://colab.research.google.com/github/franciscoandrade90/deep-learning-practicals/blob/main/gans/gan_practical.ipynb)

On Colab, start with **File → Save a copy in Drive**, so that your work is saved. Nothing needs to be installed: the first cell of each notebook downloads its helper file.

To run the notebooks on your own computer (VS Code or Jupyter), download this repository (**Code → Download ZIP**) and install the libraries, ideally in a virtual environment:

```
pip install -r requirements.txt
```

In VS Code, you also need the Jupyter and Python extensions.
